# Sponsor Curation & Tiered Architectural Hierarchy

A livery without a structured sponsor hierarchy looks like an amateur sticker bomb. Professional motorsport and authentic street tuners adhere to a strict architectural zoning system that balances commercial visibility with aesthetic composition.

---

## 1. The 4-Tier Sponsor Real Estate Model

```
+========================================================================+
|                       TIER 1: TITLE BILLBOARD                          |
|  • Real Estate: Mid-Door Center, Full Hood Expanse, Rear Wing Blade    |
|  • Visual Share: ~50% of all typography                                |
|  • Function: The primary corporate backer funding the team / car       |
|  • Examples: CALSONIC, CASTROL, MOTUL, PENNZOIL, RAYBRIG, ADVAN, HKS   |
+========================================================================+
                                   |
                                   v
+========================================================================+
|                       TIER 2: CO-SPONSORS                              |
|  • Real Estate: Rear Quarter Panel Flanks, Front Bumper Outer Edges    |
|  • Visual Share: ~25% of typography                                    |
|  • Function: Major technical, fuel, or tire partners                   |
|  • Examples: MOBIL 1, BRIDGESTONE, DUNLOP, IDEMITSU, BBS, PIAA         |
+========================================================================+
                                   |
                                   v
+========================================================================+
|                  TIER 3: TECHNICAL VERTICAL STACK                      |
|  • Real Estate: Front Fender (behind wheel) or Leading Edge of Door    |
|  • Visual Share: ~15% of typography                                    |
|  • Function: Mechanical suppliers arranged in strict functional order  |
|  • Hierarchy: Engine/ECU -> Suspension -> Brakes -> Wheels -> Tires    |
+========================================================================+
                                   |
                                   v
+========================================================================+
|             TIER 4: SCRUTINEERING & CONTINGENCY DETAILS                |
|  • Real Estate: Lower Bumper, A-Pillar, Roof Hatch, Mirrors            |
|  • Visual Share: ~10% of typography                                    |
|  • Function: Sanctioning body tags, safety markers, driver identity    |
|  • Examples: TOW arrows, Kill switch triangles, Race Number Plates     |
+========================================================================+
```

## 2. The Strict Tier 3 Vertical Stack Anatomy

The vertical stack on the front fender is one of the most recognizable features of GT and touring car liveries. It must NOT be arranged randomly. Follow this top-to-bottom mechanical order:

1. **Engine Tuning / ECU:**
   - Nissan: `NISMO`, `TOMEI`, `JUN`
   - Honda: `MUGEN POWER`, `SPOON SPORTS`
   - Toyota: `TRD`, `TOM'S`
   - Subaru: `STI`, `CUSCO`
   - Universal: `HKS`, `GREDDY`, `APEXI`, `BLITZ`
2. **Suspension & Chassis:**
   - `TEIN`, `BILSTEIN`, `ÖHLINS`, `KW`, `CUSCO`, `TANABE`
3. **Braking Systems:**
   - `ENDLESS`, `PROJECT MU`, `BREMBO`, `AP RACING`, `WINMAX`
4. **Forged Competition Wheels:**
   - `RAYS / VOLK RACING`, `WORK WHEELS`, `ENKEI`, `BBS`, `SSR`, `WEDSSPORT`
5. **High-Performance Tires:**
   - `BRIDGESTONE POTENZA`, `YOKOHAMA ADVAN`, `TOYO PROXES`, `DUNLOP DIREZZA`, `FALKEN AZENIS`
6. **Lubricants & Engine Protection:**
   - `MOTUL 300V`, `CASTROL EDGE`, `MOBIL 1`, `WAKO'S`, `IDEMITSU`
7. **Cockpit & Safety Hardware:**
   - `TAKATA`, `BRIDE`, `RECARO`, `SPARCO`, `OMP`, `SABELT`

## 3. Typographic Legibility & Contrast Rules

- **Decal Color Consistency:** The Tier 3 vertical stack should be rendered in a **single uniform color** (typically Pure White `#FFFFFF` on dark cars, or Gloss Black `#000000` on bright cars). Introducing multi-colored logos into a small vertical stack turns into visual mud.
- **Letter Spacing & Aspect Ratio:** Never stretch or distort official corporate sponsor wordmarks. Scale them proportionally.
- **Background Protection:** If the livery graphic features busy patterns (such as geometric camouflage or splatter), place a solid rectangular or capsule backing behind the sponsor typography to maintain instant readability.
